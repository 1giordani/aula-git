# Descrição para a DIO

Piano virtual desenvolvido com HTML5, CSS3 e JavaScript puro, baseado no projeto de Felipe Aguiar para a DIO. Utiliza manipulação do DOM, eventos de mouse, toque e teclado e reprodução de 17 amostras de áudio locais. Inclui controle de volume, opção de silenciar, exibição das letras, feedback visual e reprodução simultânea de notas diferentes. O projeto possui layout responsivo, navegação por teclado e testes automatizados do núcleo de áudio.
