# Descrição para a DIO

Landing page desenvolvida com HTML5 e CSS3 para o desafio da Trilha de CSS da DIO. O projeto aplica seletores, box model, tipografia, gradientes, imagens de fundo, Flexbox e Grid. Inclui layout responsivo, navegação por teclado, foco visível e documentação no README. A página apresenta os módulos da formação e links para a plataforma DIO, sem utilizar frameworks.
