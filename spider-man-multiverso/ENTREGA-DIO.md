# Descrição para a DIO

Site Multiverso Spider-Man desenvolvido com HTML5, CSS3 e JavaScript puro, inspirado no projeto da DIO. Explora animações, transformações 3D, sobreposição de blocos, posicionamento, filtros e transições. Inclui carrossel interativo, três universos, seleção de oito filmes, galeria ampliável, player de vídeo, layout responsivo e navegação por teclado. O projeto possui documentação e testes automatizados do catálogo e das rotas.
