# Descrição para entregar na DIO

Jogo Detona Ralph desenvolvido com HTML5, CSS3 e JavaScript puro, baseado no projeto da DIO. A aplicação utiliza manipulação do DOM, eventos, temporizadores e geração de posições aleatórias. Inclui pontuação, três vidas, contagem regressiva, níveis de dificuldade, pausa, reinício, efeitos sonoros opcionais e recorde salvo no navegador. O projeto possui layout responsivo, controles por teclado, recursos locais e testes automatizados das regras do jogo.
