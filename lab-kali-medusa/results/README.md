# Resultados de simulação offline

Os arquivos JSON desta pasta foram gerados pelos scripts incluídos, sem rede e sem VMs. São evidências da execução local da simulação, não de testes em FTP, SMB ou DVWA. O planejamento DVWA também informa zero requisições.

Reproduza na raiz do projeto com os comandos do README. Os dez testes incluem transporte HTTP falso; nenhum deles autentica em um serviço real.
