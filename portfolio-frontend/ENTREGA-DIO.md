# Descrição para a DIO

Portfólio front-end de Giordani Martins Silva desenvolvido com HTML5, CSS3 e JavaScript puro, inspirado no desafio da DIO. Reúne oito projetos de estudo com links para o GitHub e apresenta filtros por categoria, busca por tecnologia, temas claro e escuro e menu responsivo. O projeto aplica HTML semântico, Grid, Flexbox, manipulação do DOM e acessibilidade, com documentação das decisões técnicas e testes automatizados do catálogo e dos filtros.
