# Descrição para a DIO

Jogo da memória com emojis desenvolvido em HTML5, CSS3 e JavaScript puro, baseado no desafio da DIO. O projeto trabalha manipulação do DOM, eventos, arrays e temporizadores, com embaralhamento Fisher–Yates, comparação de pares e bloqueio de cliques inválidos. Inclui contador de jogadas, cronômetro, recorde local, reinício sem recarregar a página, layout responsivo, navegação por teclado e testes automatizados das regras.
