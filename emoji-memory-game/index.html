Como jogar

Vire duas cartas por jogada. Se forem iguais, o par fica aberto. Se forem diferentes, as cartas fecham após 850 milissegundos. Encontre os oito pares usando o menor número de jogadas.

No teclado, use Tab para escolher uma carta e Enter ou Espaço para virar. O recorde registra o menor número de jogadas neste navegador. Uma nova partida zera o tempo e embaralha as cartas.
