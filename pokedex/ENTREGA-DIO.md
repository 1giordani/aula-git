# Descrição para a DIO

Pokédex desenvolvida com HTML5, CSS3 e JavaScript puro, consumindo a API REST PokéAPI. O projeto apresenta os 151 Pokémon da primeira geração com busca por nome ou número, filtro por tipo, ordenação, paginação e modal de detalhes. Inclui layout responsivo, cache local, tratamento de erros, controle de requisições simultâneas e testes automatizados da camada de dados.
