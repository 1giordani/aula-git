# Descrição para entregar na DIO

Jogo Yu-Gi-Oh! Jo-ken-po Edition desenvolvido com HTML5, CSS3 e JavaScript puro, utilizando os recursos fornecidos pela DIO. O projeto aplica gerenciamento de estado, funções, eventos, manipulação do DOM e sorteio de cartas. Inclui regras de pedra, papel e tesoura, placar, histórico de rodadas, efeitos sonoros opcionais, reinício e vitória ao alcançar cinco pontos. A interface é responsiva, permite navegação por teclado e possui testes automatizados das regras.
