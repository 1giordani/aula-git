# Descrição para a DIO

Landing page Mundo Invertido desenvolvida com HTML5, CSS3 e JavaScript puro, inspirada no projeto da DIO. Inclui alternância de temas com preferência salva, mudanças visuais dos personagens, galeria, trailer e formulário demonstrativo com validação dos campos. O projeto aplica HTML semântico, variáveis CSS, Grid, Flexbox, responsividade, manipulação do DOM e acessibilidade. Possui README e testes automatizados da validação, sem envio ou armazenamento dos dados do formulário.
